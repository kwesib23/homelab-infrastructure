# homelab-infrastructure

Proxmox, Linux, and Kubernetes home lab for infrastructure engineering and CKA preparation.

This hands-on lab starts with a Dell OptiPlex 790 selected as the Proxmox host. The projects build from installing the hypervisor to administering Linux VMs and practicing for the Certified Kubernetes Administrator (CKA) exam.
