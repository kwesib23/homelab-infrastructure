# Roadmap

The [progress log](PROGRESS.md) records completed work. These milestones describe upcoming lab work.

1. [Proxmox installation](projects/01-proxmox-installation/README.md) — Confirm the hardware, prepare the installer USB, install Proxmox VE, and verify disk boot and management access.
2. [Linux virtual machines](projects/02-linux-virtual-machines/README.md) — Use the verified host to provision Linux guests and validate boot, access, networking, and updates.
3. [Kubernetes lab](projects/03-kubernetes-lab/README.md) — Use the Linux guests to build and verify a cluster, then practice CKA administration and troubleshooting tasks.
